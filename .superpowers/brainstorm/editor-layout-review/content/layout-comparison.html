拟写入文档的关键规则

  • 布局仅在 MCBE 游戏窗口内渲染，不启用 ImGui Docking、Multi-Viewport 或独立 OS 窗口。
  • Details 宽度与 Timeline 高度分别持久化；允许从紧凑编辑到大幅扩展，且保留最小可用的游戏视口。
  • Viewport 是上方主区域：先分配菜单、状态栏、时间轴和右栏，再由剩余矩形完整承载游戏画面。
  • 导出配置界面不常驻、不作为页面入口；仅点击 File → Export… 后出现，确认开始导出才切换到 Render 进度页。
