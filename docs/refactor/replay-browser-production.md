# 回放菜单生产实现

## 需求

提供全屏回放目录，统一编辑器配色，使用 TTF 图标，文本字号为 16 至 26 像素。支持搜索、排序、平铺和详情视图、打开、编辑入口及二次确认删除。卡片为 4:3 容器，详情预览为 16:9 容器。

## 架构

`ReplayBrowser` 负责解析和打开回放；`ReplayBrowserWindow` 仅维护展示状态、稳定回放 ID 选择、派生过滤索引和 ImGui 交互。平铺视图采用可见行裁剪，避免一次绘制所有卡片。详情视图复用同一选择状态和元数据源。缩略图解码和 GPU 上传由渲染器资源服务管理，缺失时保持主题封面。

## 执行

菜单打开时加载回放摘要，搜索或排序改变时重建索引，刷新后按 ID 保留有效选择。删除在确认窗口中执行并重新加载。打开和编辑均进入回放编辑器。验收包括全屏输入独占、排序后选择正确、窄宽度详情可访问、海量回放仅绘制可见卡片、构建通过。
